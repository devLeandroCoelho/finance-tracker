Personal finance management app to track income, expenses, and balance — all in one place.

## Features

- Income and expense tracking with categories
- Interactive dashboard with charts
- Monthly balance control
- Custom categories for transactions
- Clean, intuitive interface

## Tech Stack

| Layer | Technology |
|-------|------------|
| Markup | HTML5 |
| Styling | CSS3 |
| Interactivity | Vanilla JavaScript |

## Quick Start

```bash
# Clone the repository
git clone https://github.com/devLeandroCoelho/finance-tracker.git
cd finance-tracker

# Open in browser
open index.html
```
